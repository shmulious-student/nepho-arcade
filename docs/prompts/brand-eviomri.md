# EVIOMRI brand art — launcher icon + Android splash, 2 image requests

## Status — open (not in the character queue) · 2 image requests

The game was renamed **EviOmri** (from "Nepho") on 2026-09-13. What already reads EVIOMRI for real:
the page title, the lobby wordmark (`public/assets/generated/ui/logo.svg`, vector, regenerated by
`tools/build-ui-assets.mjs`), the Boot/Lobby caption, the Android app name and the APK file name.

What is an **interim patch**: the launcher icon (`public/assets/generated/ui/icon-512.png` → the
`android/app/src/main/res/mipmap-*/ic_launcher*.png` set) and the Android splash
(`public/assets/generated/ui/splash.png` → `android/app/src/main/res/drawable-xxhdpi/splash_art.png`)
are the old NEPHO paintings with the wordmark band covered and "EVIOMRI / CIRCUIT BREAKERS" re-drawn
over it by a script. They look acceptable but the splash's cast (four armoured cyber-soldiers) never
was this game's cast. The originals are in `public/assets/backups/brand-nepho/`.

Done means: two new images saved over `icon-512.png` and `splash.png` in `public/assets/generated/ui/`,
then derive the Android set (see "After delivery").

`public/game/cards/shmuel.webp` + `public/game/cards/eviatar.webp` (the render style of the game).

> other text anywhere. Clean pixel-art-inspired painted style, crisp edges, no photo texture, readable
> at 48 px.

## After delivery

```bash
# icon → web + Android mipmaps (launcher, round, adaptive foreground); splash → web + Android
node - <<'JS'
import('sharp').then(async ({ default: sharp }) => {
  const R = 'android/app/src/main/res/', U = 'public/assets/generated/ui/';
  const icon = await sharp(U + 'icon-512.png').resize(512, 512).png().toBuffer();
  await sharp(icon).toFile('public/game/ui/icon-512.png');
  for (const o of [U + 'icon-192.png', 'public/game/ui/icon-192.png']) await sharp(icon).resize(192, 192).toFile(o);
  for (const [d, px] of Object.entries({ mdpi: 48, hdpi: 72, xhdpi: 96, xxhdpi: 144, xxxhdpi: 192 })) {
    await sharp(icon).resize(px, px).toFile(`${R}mipmap-${d}/ic_launcher.png`);
    await sharp(icon).resize(px, px).toFile(`${R}mipmap-${d}/ic_launcher_round.png`);
    const fg = Math.round(px * 108 / 48), inner = Math.round(fg * 310 / 432), off = Math.round((fg - inner) / 2);
    await sharp({ create: { width: fg, height: fg, channels: 4, background: { r: 0, g: 0, b: 0, alpha: 0 } } })
      .composite([{ input: await sharp(icon).resize(inner, inner).toBuffer(), left: off, top: off }]).png().toFile(`${R}mipmap-${d}/ic_launcher_foreground.png`);
  }
  const splash = await sharp(U + 'splash.png').resize(1920, 1080).png().toBuffer();
  for (const o of ['public/game/ui/splash.png', R + 'drawable-xxhdpi/splash_art.png']) await sharp(splash).toFile(o);
});
JS
npm run build && npm run android:apk && npm run content:deploy
```
